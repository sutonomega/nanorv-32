# 起動・転送 — Draft 0.1

> PR #17で承認された[実装基準仕様](baseline-v0.md)の§4・6が本稿に優先する。[検証ベクター](protocol-vectors.py)はPython 3.12で実行可能。

候補手順: リセット → CPU停止 → 同期/コマンド/長さ/ペイロード/CRCを受信 → RAMへ書込み → 検証成功 → PC=0で開始 → UARTをアプリへ切替。CRC検証失敗時は実行しない。

CPU停止中だけRAMを変更する。実行中の強制停止やレジスタデバッグは将来候補。初期の復旧はボードリセットでローダーへ戻す案。転送失敗時の中途半端なRAM内容を実行できない設計にする。

未確定: baud/8N1採否、同期語、各フィールド幅/バイト順、コマンド値、CRC32の多項式・初期値・反転・最終XOR・対象範囲、上限長、書込み先/開始PCの指定可否、ACK/NACK、タイムアウトと再同期。#5のバイト列例とPC/FPGA共通テストベクトルが揃うまで実装契約としない。
