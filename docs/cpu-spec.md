# CPU仕様 — Draft 0.1

候補: XLEN=32、x0〜x31（x0は常に0）、32bit固定長命令、little endian、開始PC=0、非パイプライン。整列アクセスを基本とし不整列は検出する案。

段階的にADDI/ADD/SUB/LUI、論理・シフト、LW/SW、分岐・JAL/JALR、残りのRV32Iを追加する。v0.1は部分実装でありRV32I互換を宣言しない。

全命令の対象: LUI/AUIPC、JAL/JALR、6分岐、5ロード、3ストア、9即値演算、10レジスタ演算、FENCE、ECALL/EBREAK。FENCE.IとCSR命令は別拡張として扱い、Machineモードの実装範囲と混同しない。

未実装・不正命令を無視せず停止通知する案。trap通知だけでは特権仕様準拠とはしない。ECALL/EBREAK、FENCE、命令・データ不整列、アクセス違反の実行環境動作、原因/PCの保存と観測手段、レジスタ初期値は#2で決定する。#10で対象仕様版と適合表を記録する。
