# メモリマップ — Draft 0.1

全アドレスは候補。変更はCPU・ローダー・リンカへ同時反映する。

| アドレス | 候補用途 |
|---|---|
| 0x00000000–0x00003FFF | 共用RAM 16 KiB |
| 0x10000000 | UART TX |
| 0x10000004 | UART RX |
| 0x10000008 | UART STATUS |
| 0x10000100 | LED |
| 0x10000200 | タイマー値 |
| 0x10000204 | タイマー制御 |

STATUS bit0=受信あり、bit1=送信可能という案。MMIOは32bit整列アクセス案。RAMはバイトストローブを持つ。

未確定: 各レジスタR/W属性・リセット値・予約ビット・読み書き副作用・満杯/空時・幅違反・未割当アクセス。タイマー幅/分周/折返しと割り込みの有無も#4で決定する。OSとアプリ領域の分割は#14で決定する。
