# 要求仕様 — Draft 0.1

> PR #17で承認された[実装基準仕様](baseline-v0.md)の§1が本稿に優先する。

確定した目的: Tang Nano 9Kで自作RV32I CPUと小型OSを開発し、CPUとOSの双方を発展させる。PCを操作端末として使用する。

候補: Verilog、非パイプラインのマルチサイクルCPU、命令・データ共用16 KiB RAM、UART、LED、タイマー。初期は乗除算・キャッシュ・外部RAM・割り込みを対象外とする案。Linuxは初期目標に含めない。

未確定: 正確なボード版・FPGA型番・資源予算・目標周波数・ツール・ライセンス・OSの保護と並行実行の要否。#1 / #6 / #14 で判断する。PSRAM・Flash・パイプライン・RV32Mはv1.0後の候補であり約束しない。
